Run `.venv/bin/python scripts/stress-tests.py --output ~/work/swarm-stress` from a checkout with requirements installed. Defaults: 15 runs each for memory/file/sqlite and eight for Postgres, sequentially, under four CPU busy loops (or twice CPU count if smaller). `--runs`, `--postgres-runs`, `--backends`, and `--load-workers` adjust the matrix. Coordinate load on shared machines; `--load-workers 0` uses existing load.

Postgres requires `initdb` and `pg_ctl` on PATH or `--pg-bin /path/to/bin`. The runner initializes its own UTF8 cluster with local trust authentication on a private loopback port. It stops and removes that cluster on completion or interruption. It never accepts an existing database configuration. For extracted PostgreSQL packages, set `LD_LIBRARY_PATH` to their matching library directory before launch. Do not run as root (`initdb` refuses it).

The output directory must be new and outside `/tmp`; test temporary files also live there. Each run discovers all `test_*.py` tests, including the Postgres stall recovery tests which CI runs separately. Offline runs use `SWARM_TEST_BACKEND`; Postgres uses the generated `SWARM_TEST_CONFIG`. Full logs, incremental test IDs and traceback tails (`failures.jsonl`), results (`outcomes.json`), source revision/load metadata (`metadata.json`), and a flake table (`flakes.md`) remain for review. A table denominator is the number of completed runs for that backend. Multiple failures from a test in the same run count once. An interrupted or timed-out suite is a runner failure rather than a successful run. Exit status is nonzero if any suite fails. Per-suite timeout defaults to 900 seconds; raise it explicitly if the host cannot finish a full suite within that time.

Baseline evidence for the flaky-tests job is retained under `/home/codex/work/finder-baseline-full` on the coder box. It runs the product and tests from origin/main `0646bf6`; only this runner and its notes differ. Parameters are eight runs per offline backend, four Postgres runs, four load workers, and `--timeout 7200`. Earlier partial evidence in `finder-baseline-runs` is excluded from the completed-run counts because that invocation was stopped to raise its 900-second safety timeout.
