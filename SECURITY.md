# Security policy

Only the latest release is supported.

Report a vulnerability privately through a
[GitHub security advisory](https://github.com/fcarucci/Swarm/security/advisories/new) on
fcarucci/Swarm, or by email to francesco@carucci.org. Please do not open a public issue for it.

Swarm's threat model and known limits are in
[docs/REFERENCE.md](docs/REFERENCE.md#security-model-and-known-limits).
